# Claudeflare Research Docs Archive

Archived research documentation for the Claudeflare project.

This repository is a snapshot of the `projects/claudeflare-archive/research-docs/`
directory recovered from a local working folder. It is preserved for reference
and historical context.

## Contents

`research-docs/` — the original document set, including:

- `AUTHENTICATION.md`, `AUTHENTICATION_GUIDE.md` — auth flow and guide
- `GITHUB-INTEGRATION-SUMMARY.md` — GitHub App / Durable Object integration notes
- `security-architecture.md` — security model
- `webrtc-datachannel-rpc-research.md` — WebRTC data-channel RPC research

## Note on credentials

The documents contain **placeholder** credential values only (for example
`"password": "password"`, `GITHUB_PRIVATE_KEY = "-----BEGIN PRIVATE KEY-----\n..."`).
No live secrets are present. Any real credential should live in a secret
manager, never in a document like these.
